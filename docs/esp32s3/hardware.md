# 元回路との照合・配線変更

調査対象: master `eef729041b61eb9d43cc1621082516c81ce04cbc`。
「確認済」は資料上の確認であり、ユーザー所有基板の導通・実装値を測定した意味ではない。

## 資料と不整合

- 添付 `opentempescope.pdf` とrepoの `hardware/OpenTempescope/opentempescope.pdf` はSHA-256が一致:
  `29f9b08ffe1d33150fcc2ffc0345764383f5f232afc83a5cd216f2d81d1fd724`。
- 添付 `OpenTempeScope_105_3700.pdf` は筐体・アクリル部品の寸法図。電気回路図ではない。
- AVRの `OpenTempescope.ino`、`PinController.cpp`、`LightController.cpp` と、PDFおよびEAGLE `.sch` のpinrefを照合した。
- **霧制御不一致**:ファームはD13/PB5/物理19。PDFと.schはTD62083入力4からAVR物理18へ接続。物理18は**PB4/D12**で、図の `18-PB5(MISO/PCINT4)` はPB5の誤記。ファームD13を正しい回路接続として転記してはいけない。
- RGBのファーム意図はTD入力6=R、7=G、5=Bだが、PDF/.schのLED接続は6=R、5=G、7=B。G/Bが逆。LEDの実物ピン番号／色は導通と単色点灯で確認する。
- PDFのLED抵抗はR4=75k、R5=150k、R6=75k。EAGLEはR4=CRED/75k、R5=CBLUE/150k、R6=CGREEN/75k。**抵抗番号だけで色を指定しない**。
- ポンプR3=150k、R2=10kという値はPDF/BOM/.schで一致。5V入力でも無負荷分圧は0.3125V、3.3Vなら0.206Vとなり2N3904を十分駆動できない。150Ω等の誤記の可能性はあるが未確定。
- `.sch` のN$11（リレー1）とN$12（TD15）は端点座標が一致する別名net。PDFは連続線として描かれる。実物はリレー1-ドライバ出力間の導通確認を要する。
- U$1はHPH05001Mと指定される一方、出力は12V、後段はLM7805。新電元HPシリーズ資料p83の表ではHPH05001Mは5V/1A、調整3〜11V、入力24〜40V。12V/1AはHPH12001M（調整8〜24V）であり、原図に型番不整合がある。刻印と実測を確認する。

## AVR全端子

ATmega328PのDIP28番号。図の誤記とArduino番号を区別する。制御はいずれも入力HIGHで負荷ON、RGBは正論理PWM（TD出力が電流を吸い込む）。

|2|PD0 / D0 RX|BLE_TX→AVR。外付けBLE撤去|
|3|PD1 / D1 TX|AVR→BLE_RX。外付けBLE撤去|
|4|PD2 / D2|R3→T1ベース、ポンプ制御。ファーム一致|
|5|PD3 / D3|未接続|
|6|PD4 / D4|未接続|
|7|VCC|5V。XIAO GPIOへ接続禁止|
|8|GND|図で配線なし。実基板GND接続要確認|
|9|PB6 / XTAL1|16MHz共振子。撤去可|
|10|PB7 / XTAL2|16MHz共振子。撤去可|
|11|PD5 / D5 PWM|TD入力5→出力14→LED緑経路。ファームはBと命名|
|12|PD6 / D6 PWM|TD入力7→出力12→LED青経路。ファームはGと命名|

|21|AREF|未接続|

TD62083の対応はI1/O1=1/18から順に、I5/O5=5/14、I6/O6=6/13、I7/O7=7/12、I8/O8=8/11。
「D6がG、D5がB」は**ファームの命名**であり、回路図の色接続とは逆になる。新配線は次の表の**PDFの色文字に合わせた電流経路**を採用し、単色確認で確定する。

## XIAO推奨配線（新仕様）

AVRは取り外す。AVR出力とXIAO出力を並列接続しない。元の外付けBLEと共振子は不使用。
全GNDを共通にする。ポンプ大電流の戻りをXIAOの細いGND配線に通さない。

|機能|XIAO端子|SoC GPIO|接続先・変更|
|---|---|---:|---|
|ポンプ|D0|1|100Ω→Qpゲート。Qp D=PUMP_GND、S=GND、G-S=10k（R2流用可）|
|ミストリレー|D1|2|100Ω→Qmゲート。Qm D=リレー1、S=GND、G-S=100k。リレー1とTD15を切り離す|
|ファン|D3|4|TD62083入力8。出力11→DCFAN_GND、ファン＋=5V|
|赤PWM|D4|5|TD入力6→出力13→PDFのR抵抗→赤カソード|
|緑PWM|D8|7|TD入力5→出力14→PDFのG抵抗→緑カソード|
|青PWM|D9|8|TD入力7→出力12→PDFのB抵抗→青カソード|
|ポンプ水位|D6|43|1k直列→安全水位で閉じる接点→GND。GPIO側10kで3.3Vへpull-up|
|ミスト水位|D7|44|同上。独立水域なら別スイッチ。同じ水域なら高い安全水位を保証する1接点を共用可|
|停止ループ|D10|9|NC接点→GND。GPIO側10kで3.3Vへpull-up|
|故障解除|D5|6|NO押しボタン→GND。入力pull-up。故障解除のみ、運転開始しない|
|予備|D2|3|strapping端子のため不使用|
|電源|5V|—|逆流対策した安定化5Vのみ|
|GND|GND|—|既存電源GNDへ|

**Config.hはこの表（G=GPIO7→TD入力5、B=GPIO8→TD入力7）に従う。**
元ファームの色名順のままソケットへ結線するとG/Bが逆になる可能性がある。既存基板の実配線が修正済みなら、色検査後に接続先を入れ替える。

GPIO43は起動時にUART TXとして動く場合があるため水位接点へ直結せず1k直列を必須とする。USB CDCを使用し、Serial1は使わない。
TD入力5/6/7/8には各10kの対GNDプルダウンを追加。未使用入力1/2/3/4をGNDへ固定。TD pin9=GND、pin10=**5V**のクランプ共通でありロジック電源入力ではない。

リレーはコイル16=5V、1=Qmドレイン。追加ダイオードはアノード=1、カソード=16。
霧発生器＋は24V、−はリレー13、リレー9=GND（非励磁で開放のNO側）。底面図と実物の向きを確認する。24VをXIAOやリレーコイルへ入れない。

損失の目安:TDはΣ(Iout×VCE)+入力分。50mAファンでVCE=1Vなら50mW、3色各3mAなら9mW程度が追加。例示値であり測定値ではない。
Qpは1Aなら25℃の48mΩから約48mWという計算例。ただし高温抵抗・始動／拘束時間・配線・SOAを別途評価する。

## 追加部品と変更箇所

|区分|部品・数|目的／省略条件|
|---|---|---|
|推奨必須|AO3400A等ロジックN-MOSFET 2個＋変換基板|T1置換とリレー低損失化。電流測定で他のFETが必要なら再選定|
|必須|100Ω 2本、100k 1本|ゲート直列、Qmプルダウン。Qpは既存R2=10kを流用|
|必須|1N4007等 1本|Qmへ移したリレーコイルの逆起電力。ポンプの既存D1は向き・定格を確認して流用|
|必須|10k 7本、1k 2本|TD入力プルダウン4、水位2＋停止1のpull-up、UART兼用水位入力の直列抵抗|
|必須|水位接点1〜2個|両アクチュエータの最低水位を上回る位置、安全時閉。防滴配線。別水域では2個|
|必須|停止用NC接点1個|NCは断線でも停止。真の電源断には別極／別スイッチで負荷電源を遮断する|
|任意|NO解除ボタン1個|Serialのresetでも解除できるため、省略可能|
|推奨|入力24V対応5V buck 1台、逆流防止素子、デカップリング|XIAO用5V。最低1A級を候補にして負荷応答確認。24V入力上限に余裕を確保|
|条件付き|LED直列抵抗3本交換|型番・Vf・許容電流確定後にR=(5−Vf−VCE)/Iで決定。単色確認は1kΩ以上＋電流制限から。75k→75Ωと決め打ちしない|
|条件付き|ファン用MOSFET＋ダイオード|TD降下で起動できない／電流・発熱不適合時のみ追加|
|配線条件次第|ヒューズ・接続材・バルク容量|電源／負荷保護。定格は測定後決定。XIAO近傍0.1µF＋10µF、過渡が残る場合だけ容量増加|

既存T1、R3を外し、PUMP_GNDをQpへ接続。既存TD15-リレー1を切り、Qmへ変更。RGB、ファン、リレー接点、ポンプD1、既存電源は適合確認できたものを流用する。
XIAO 5V入力はSeeedの指示に従い外部電源→ダイオード→5V。USB接続時の逆流／外部側への逆給電も確認し、評価中はUSBと外部5Vを同時に接続しない方法が確実。
**5Vと3.3Vを接続しない。** 水位入力に5Vモジュール出力を接続しない。高湿度の展示室と基板室を分離する。
